# BlueRyder

BlueRyder is a web and scripting framework built on PowerShell 5 and .NET Framework. This allows it to run on any currenlty supported Windows installation without installing any dependencies.


## How to use
Run BlueRyder.ps1 from the same directory that it is located, you can also run the kernel directly but you will have issues with POST requests.
Server settings are set in Server.ini


## Features
- GET and POST requests
